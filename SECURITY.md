# Security policy

During the release-candidate period, ViralScan 3.0 development receives security
fixes. After 3.0 is stable, the latest stable 3.x line will receive security and
correctness fixes. Pre-v3 scientific output formats are unsupported because their
corrected counts are incompatible with the molecule-counting contract.

Report suspected vulnerabilities privately through GitHub Security Advisories.
Do not attach human-subject FASTQs, H5AD files, clinical metadata, credentials, or
institutional paths. Include the affected version, operating environment, minimal
synthetic reproduction, and impact. Maintainers will acknowledge a report within
seven days and coordinate disclosure after a fix is available.
