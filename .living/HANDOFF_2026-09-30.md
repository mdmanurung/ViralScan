## 4. Decisions you must follow (full table: PLAN.md § WP1E)

- **Virus key** (`virus_identity.py`):
  - non-segmented viruses use the NCBI taxid;
  - a segmented isolate shares its taxid with its segments. A taxid is split
    by normalised strain only when it holds a segment twice (only 11320,
    "Influenza A virus");
  - anelloviruses use the genus (`genus:<Genus>`), taken from the anello
    accession table, else the ICTV-named catalogue genus, else
    "Anelloviridae". Reason: 4 of 120 anello taxids span several genera;
  - uncatalogued genomes use `accession:<acc>`; a legacy 3-column t2g uses
    `name:<legacy>`.
- **Viral/host resolution**, first match wins:
  1. `catalogued`: t2g column 5 is a catalogue accession;
  2. `uncatalogued`: the gene is in the GTF gene set and its column 5 is
     **not** a transcript of the index;
  3. otherwise `host`;
  4. `legacy_prefix`: the t2g has no column 5.

  Zero viral genes raises `ValueError`.
- **Q8:** an index **build manifest** records the host and viral gene sets
  and overrides `--gtf`. Runs that contradict it are refused. This is
  `DEF-03`, folded into step 4. The structural guard from rule 2 stays as a
  backstop.
- **Specificity (R2.3):** zero probable or strong calls on the negative
  controls binds every default.
- **Tuning:** no tuning run before gate G4 (R2.4). Already-seen datasets are
  never used for tuning (R2.2).
- **Releases (R3.5):** `3.0.0.devN` git tags only. The user signs off the
  protocol freeze, the defaults freeze, unblinding, rc1, 3.0.0 and any
  retraction.
- **Coordination (Q2, Q10):** one orchestrator writes PLAN.md, `.living/`,
  the inventory, the registry and the protocol. Subagents commit on `v3/*`
  branches and only the orchestrator merges. At most 3 implementers at once.

## 5. Findings from this session (in `.living/findings/`)

- **F-017** (`ebv-type2-sibling-dilution-equal-split.md`):
  - on the max panel, EBV type 2 takes **16.1 %** of EBV molecules through
    the equal split of shared equivalence classes (EBV-1 743,325; EBV-2
    142,963);
  - this holds with barcode correction on;
  - fix: sibling grouping (MECH-A step 4, MECH-B) and a within-group
    allocation (`DEF-06`, grill R2.5).
- **F-018** (`dropseq-kb-allowlist-prefilter.md`): since SW-13, a Drop-seq run
  without `-w` is corrected against kb's **data-derived allowlist**. HSV-1
  SRR8315713 keeps 5,468 of 1.8M barcodes and loses 28 % of its molecules.
  10x runs correct against the official on-list (EBV −2.2 %). The decision
  belongs to MECH-D (PLAN `SW-21`).
- **F-019** (`covid-anellovirus-signal-is-polyg-reads.md`): the published covid
  Alphatorquevirus signal (1.17M / 1.61M) is:
  - **~90 % poly-G no-signal reads** (two-colour chemistry);
  - ~10 % host-homologous reads;
  - **0 clean viral reads**.

  Tonsil x223 reproduces it (3.02M reads), and current code reproduces the
  covid numbers. This refines F-005's mechanism. A low level of divergent TTV
  is still not excluded.
- **F-020** (`fiveprime-strand-default-loses-reads.md`): on 10x 5′ libraries
  kallisto's forward default pseudoaligns **6.5–8.9 %** of reads (reverse
  46–53 %, unstranded 53–60 %).
  - The poly-G artefact is forward-only.
  - HHV-6B viral UMIs are highest with unstranded.
  - Every 5′ number so far (covid, HHV-6B, tonsil) was computed on about
    7–9 % of the reads.
